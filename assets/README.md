# Game Assets Directory

Place your original Japanese or patched English DoJa game files in this directory:

- `assets/pon/` — `PoN.jar`, `PoN.sp`, and optional `PoN.jam`
- `assets/lon/` — `LoN.jar`, `LoN.sp`, and optional `LoN.jam`

The `.gitignore` file excludes `.jar`, `.sp`, `.jam`, and `.sav` files from version control.
